🎲 **Sorteador Simples**
<br>

Um sorteador feito com HTML, CSS e JavaScript para gerar números aleatórios de forma prática e intuitiva!
<br>


🚀 **Funcionalidades**
- Gera um número aleatório dentro de um intervalo definido pelo usuário.
- Interface simples e responsiva.
- Fácil de integrar e personalizar.
<br>

📌 **Como Usar**
- Defina o intervalo de números (mínimo e máximo).
- Clique no botão "Sortear".
- O número aleatório será exibido na tela.
 <br>
 

💻 **Tecnologias Utilizadas**
- HTML → Estrutura do sorteador
- CSS → Estilos e responsividade
- JavaScript → Lógica de geração de números
<br>


🛠️ **Como Rodar o Projet**
- Abra o arquivo index.html no navegador.
- Comece a sortear números!
 <br>
